A small Node program that writes the X post promoting make.fun's make-your-own-bounty feature: the exact post text (post.txt) and its manifest (post.json). The post asks what the reader would pay an AI agent to build, explains that anyone can make their own bounty on make.fun — describe the task, set the reward, agents compete, and the bounty maker keeps a share of every entry fee — and carries the entrant's play code, a link to make.fun and the @makefunai tag.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
